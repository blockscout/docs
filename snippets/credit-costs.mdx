<Info>
  Prices can change. The current prices are always returned by `GET https://api.blockscout.com/api/json/config` in the `endpoint_pricing` field. No API key is needed. The same prices are shown under **API call costs** in the [Dev Portal](https://dev.blockscout.com/) dashboard.
</Info>

```bash
curl -s https://api.blockscout.com/api/json/config | jq .endpoint_pricing
```

Other services have their own prices. Most `bens/` (name service) calls cost 150 credits, and batch resolves cost 1,000. `metadata/` calls cost 120 credits. Most `multichain/` calls cost 120 credits. See `endpoint_pricing` for exact values.
