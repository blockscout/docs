## Plan tiers

Every tier includes access to all 100+ Blockscout-supported chains with a single key, except [plan-restricted chains](#plan-restricted-chains-and-endpoints). Swap `chain_id` to move between chains.

| Tier | Rate limit | Credits | Price |
| --- | --- | --- | --- |
| Free | 5 RPS | 100K/day | \$0 |
| Builder | 15 RPS | 100M/mo | \$49/mo |
| Pro | 30 RPS | 500M/mo | \$199/mo |
| Business | 50 RPS | 3B/mo | \$999/mo |
| Enterprise | Custom | Custom | Contact us |

At the default 20-credit cost per call, the free tier's 100K daily credits is roughly 5,000 standard requests a day before the counter resets at midnight UTC.

## Credit cost per endpoint

Credits are consumed per API call. The default cost is 20 credits for any endpoint not listed below.

The current price list is returned by `GET https://api.blockscout.com/api/json/config` in the `endpoint_pricing` field. No API key is needed.

Requests that return a `4xx` or `5xx` status cost no credits, with one exception: a `404` returned by the chain's Blockscout instance or service (for example, for a transaction that doesn't exist) is charged at the endpoint's normal cost. A `404` returned by the Blockscout API itself (`"source": "internal"`, such as an unsupported network or unknown path) is free. For x402 requests, every `4xx` and `5xx` is free, including `404`. See [x402 payments](/devs/x402-payments#no-charge-for-error-responses).

| Endpoint | Credits |
| --- | :-: |
| `default` (all unlisted endpoints) | 20 |
| `api/v2/search/quick` | 25 |
| `api/v2/transactions/:hash/logs` | 30 |
| `api/v2/transactions/:hash/token-transfers` | 30 |
| `api/v2/transactions/:hash/state-changes` | 30 |
| `api/v2/tokens` | 30 |
| `api/v2/tokens/:address_hash/transfers` | 30 |
| `api/v2/addresses/:address_hash/token-transfers` | 30 |
| `api/v2/addresses/:address_hash/logs` | 30 |
| `api/v2/transactions/:hash/internal-transactions` | 40 |
| `api/v2/addresses/:address_hash/internal-transactions` | 40 |
| `api/v2/smart-contracts/verification/config` | 40 |
| `api/v2/transactions/:hash/summary` | 50 |
| `api/v2/transactions/:hash/raw-trace` | 50 |
| `api/v2/addresses/:address_hash/coin-balance-history` | 50 |
| `api/v2/advanced-filters` | 50 |

Other services have their own prices. Most `bens/` (name service) calls cost 150 credits, and batch resolves cost 1,000. `metadata/` calls cost 120 credits. Most `multichain/` calls cost 120 credits. See `endpoint_pricing` for exact values.

### Chain credit multipliers

Some chains have a credit multiplier. On those chains, a call costs the endpoint's credits from the table above multiplied by the chain's multiplier. Most chains have a multiplier of 1, so the table applies as is.

For example, on a chain with a multiplier of 2, a call to an unlisted endpoint costs 40 credits instead of 20, and `api/v2/transactions/:hash/summary` costs 100 credits instead of 50.

The multiplier applies to both key-based requests and [x402 payments](/devs/x402-payments). It does not apply to [WebSocket API](/devs/apis/websocket-api#billing) connections and messages, which have fixed credit costs.

To check the multipliers, call `GET https://api.blockscout.com/api/json/featured-chains`. No API key is needed. Each chain in the response has a `credits_multiplier` field. Chains that are not in the response have a multiplier of 1.

Example response (values are illustrative):

```json
{
  "8453": {
    "plans_allowed": ["Builder", "Business", "Pro"],
    "credits_multiplier": 2
  }
}
```

## Plan-restricted chains and endpoints

Some chains and endpoints are available only on certain plans. A key on another plan gets a `402` with an error such as:

- `Featured chain <chain_id> requires one of the following plans: ...`
- `Endpoint <path> requires one of the following plans: ...`

To check which chains are restricted, call `GET https://api.blockscout.com/api/json/featured-chains`. Each chain in the response lists the plans that can use it in `plans_allowed`. Chains that are not in the response are available on every plan.

To check which endpoints are restricted, call `GET https://api.blockscout.com/api/json/endpoints`. Each endpoint has a `featured_plans` field with the plans that can call it. `null` means the endpoint is available on every plan.

Example endpoint entry (values are illustrative):

```json
{
  "method": "GET",
  "paths": ["/:chain_id/api/v2/stats"],
  "featured_plans": ["Builder", "Pro", "Business"]
}
```

Neither call needs an API key. Plan restrictions don't apply to [x402 requests](/devs/x402-payments#plan-restricted-chains-and-endpoints).

## Response headers

Every response carries your current standing, so you can track usage without a separate call:

- **`x-credits-remaining`** — credits left in your current period. Resets daily on the free plan, monthly on paid plans
- **`x-ratelimit-limit`** — your plan's available RPS
- **`x-ratelimit-remaining`** — RPS headroom left in the current window

Track usage, top calls by consumption, and manage keys in real time at the [dev portal dashboard](https://dev.blockscout.com/).

## What happens over the limit

A `429 Too Many Requests` means you've exceeded your plan's RPS. You can either add a short delay between requests or move up a tier. A `401 Unauthorized` usually means the key isn't being sent correctly; double-check it against the dashboard.

## 403 responses from public explorer instances

Public per-chain explorer hosts (for example `eth.blockscout.com` or `robinhoodchain.blockscout.com`) sit behind bot protection. Scripted requests to those hosts can receive a `403` response whose body is an HTML "Just a moment..." challenge page instead of JSON. This is the bot-protection challenge blocking the request before it reaches the API, not a Blockscout API error.

For programmatic access, call the Blockscout API at `https://api.blockscout.com` with your API key instead of the public instance host. The Blockscout API returns structured JSON errors as described in [Error handling](/devs/error-responses).

## Compared to Etherscan

If you're evaluating a move from Etherscan's API, the free and paid tiers both come out ahead on rate limit and allowance at comparable price points:

|  | Blockscout | Etherscan |
| --- | --- | --- |
| Free | 5 RPS, 100K credits/day, all chains | 3 RPS, limited chains |
| \$49/mo tier | 15 RPS, 100M credits/mo | 5 RPS, 100K calls/mo |
| \$199/mo tier | 30 RPS, 500M credits/mo | 10 RPS, 200K calls/mo |

See the full [migration guide](/devs/migrate-from-etherscan) for endpoint-by-endpoint parameter mapping.
