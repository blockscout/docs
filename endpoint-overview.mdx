Blockscout's RPC API follows the same `module` and `action` format as Etherscan's or Routescan's, meaning most Etherscan calls work after you change the base URL and the chain parameter. This page lists every available endpoint.

<Note>
  This page is currently under development, check back for more complete details.
</Note>

## Switch your requests

If you are migrating to Blockscout, change the base URL. Then check specific calls to see about available paths.

|  | Etherscan | Blockscout |
| --- | --- | --- |
| Base URL | `https://api.etherscan.io/v2/api` | `https://api.blockscout.com/v2/api` |
| Chain parameter | `chainid=1` | `chain_id=1` |
| API key | `apikey=YOUR_KEY` | `apikey=YOUR_KEY` or `Authorization: Bearer YOUR_KEY` |

```text

https://api.blockscout.com/v2/api?chain_id=1&module=account&action=balance&address=0x...&apikey=YOUR_KEY
```

## How to read the tables

| Status related to Etherscan | Meaning |
| --- | --- |
| **Supported** | Available with the same module and action, or an equivalent call, and a similar response. |
| **Different** | Available, but the endpoint name, parameters or response format differ. |
| **Not available** | No equivalent in the Blockscout APIs today. |
| **Not applicable** | Specific to Ethereum proof of work or to Etherscan. |

94 Etherscan endpoints: 40 supported, 33 different, 17 not available, 4 not applicable.

Blockscout equivalents are shown as RPC (`module` and `action` on `https://api.blockscout.com/v2/api?chain_id={chain_id}`), REST (paths under `https://api.blockscout.com/{chain_id}/api/v2`), ETH RPC (`POST https://api.blockscout.com/{chain_id}/json-rpc`) and stats service (`https://api.blockscout.com/{chain_id}/stats-service/api/v1`).

Blockscout also provides endpoints with no Etherscan counterpart:

- **REST API:** transaction state changes, raw traces and summaries, NFT instance metadata and holders, address and token counters, search, CSV exports and advanced filters.
- **Account abstraction (ERC-4337):** user operations, bundlers, paymasters and factories.
- **Rollup data:** batches, deposits, withdrawals and messages for Arbitrum, Optimism, Scroll, zkSync and Shibarium.
- **RPC extras:** `pendingtxlist`, `listaccounts`, `token404tx`, `listcontracts` and `gettxinfo`.
- **Multichain search, name service and address metadata services.**
