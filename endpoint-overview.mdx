A compact list of every Blockscout API endpoint. For parameters and example responses, see the API reference.

<Info>
  **Base URLs.** Replace `{chain_id}` with the chain's numeric ID (for example `1` for Ethereum).

  - REST API: `https://api.blockscout.com/{chain_id}/api/v2`. REST paths are relative to it. Legacy routes show their full path after `https://api.blockscout.com/{chain_id}`.
  - RPC API: `https://api.blockscout.com/v2/api?chain_id={chain_id}`. Add the `module` and `action` shown in the tables.
  - ETH RPC API: `POST https://api.blockscout.com/{chain_id}/json-rpc` with a JSON-RPC 2.0 body. The method name goes in the `method` field.
  - Services (name service, address metadata, multichain search, stats): `https://api.blockscout.com`. Service paths show their full path after it. Replace `{cluster_id}` with a cluster ID.
</Info>

<Tip>
  Send your API key as the `apikey` query parameter or as an `Authorization: Bearer YOUR_KEY` header. REST list endpoints return `next_page_params`; pass those values back as query parameters to get the next page.
</Tip>

175 REST endpoints, 43 RPC actions, 16 ETH RPC methods and 38 service endpoints.

Endpoint names link to their API reference page where one exists.

<Note>
  Endpoints marked **(spec only)** come from the API specifications and have not been verified against a live API. Endpoints marked **(requires a logged-in account)** need an account session as well as an API key.
</Note>
